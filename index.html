FDTD, FEM or MoM?

Learn how the three main EM solvers work, and when to use each one. Each solver makes one main decision: what to mesh, and how to model the space around the device. This decision tells you where the solver is fast and where it is slow.

Convergence

A result is correct only when it does not change on a finer mesh. Each solver has its own rule for this. Try each demo.

Live 1D FDTD: a pulse on a grid of 240 cells

The time step has a limit

In one time step, a wave must not move more than one cell. If it does, the update cannot follow it, and small errors increase at each step. This is the Courant-Friedrichs-Lewy (CFL) limit.

In 1D, the update is stable when S ≤ 1. Move the slider above 1.0 and the field increases without limit. In 3D with cubic cells, the limit is S ≤ 1/√3 ≈ 0.577.

Δt ≤ 1 / ( c · √(1/Δx² + 1/Δy² + 1/Δz²) )

One small feature needs one small cell. That cell sets Δt for the full grid. Thus, fine details in a large domain make FDTD slow.

The adaptive loop

  1. Solve the field at one frequency, the solution frequency.
  2. Calculate the S-parameters.
  3. Calculate ΔS: the largest change of any S-parameter from the previous pass.
  4. Estimate the error in each element. Refine the elements with the largest error, frequently about 30 percent more elements.
  5. Go to step 1. Stop when ΔS is less than the target, or at the maximum number of passes. For safety, ask for 2 converged passes.

The field changes quickly near sharp metal corners and edges. Thus, the solver puts small elements there and keeps large elements where the field is smooth.

Select a solution frequency near the highest frequency that you need. A mesh that is good at that frequency is usually good at lower frequencies. The values in this demo are typical, not from a real solve.

Finer triangles, more accuracy, much more memory

MoM converges when the result does not change on smaller triangles. A usual start is an edge length of λ/10, with smaller triangles at metal edges, where the current is high.

Each inner edge is one unknown. Each unknown connects to all other unknowns, so the matrix has N² values. If you double the density, N increases approximately 4 times. Then the memory increases approximately 16 times.

Memory is for a dense matrix in double complex (16 bytes for each value). The error curve is typical, not from a real solve. MLFMM decreases the memory for large problems.

More methods

MoM has three types. The number of dimensions tells you which currents the solver permits and what its Green's function includes. Other methods are for very large or very small objects.

2D cross-section (BEM or 2D FEM)

The solver assumes that the structure is infinitely long in one direction. Thus, it solves only the cross-section. The result is R, L, G and C per unit length, Z0 and the effective permittivity. Use it for transmission lines, cables and coupled traces.

Ansys 2D Extractor (2D FEM), Polar Si9000 (BEM), MMTL (open source)

2.5D (planar, also called "3D planar")

The metal is on the layers of an infinite layer stack. The currents flow in the planes. Vias add vertical current. The Green's function includes the substrate and the ground plane, so the solver meshes only the metal. Limit: the dielectrics have no edges. Thus, the solver does not model finite boards, enclosures or bondwires correctly.

Keysight Momentum (also in RFPro), Cadence AXIEM, Cadence EMX

Sonnet: 2.5D in a closed box

Sonnet solves planar circuits in a closed metal box. It uses a box Green's function that it calculates with FFTs on a uniform grid of cells. The ports are on the box walls. Thus, de-embedding is accurate. The box walls are real, so they can resonate. Sonnet Lite is a free version with a size limit.

Sonnet Suites, Sonnet Lite (free)

3D (surfaces and wires)

The solver models metal surfaces and wires of any shape in free space. Homogeneous dielectric bodies use surface equivalence. Complex dielectric bodies need volume equations, which cost much more. Wire MoM (NEC) is the special case for most HF antennas. With MLFMM, 3D MoM can solve bodies that are 10 to 500 wavelengths long.

Simcenter Feko (Siemens), CST Integral Equation, Ansys HFSS-IE, WIPL-D, NEC-2 (public domain)

Asymptotic

The object is hundreds of wavelengths

Physical optics (PO), SBR, geometrical optics (GO) and the uniform theory of diffraction (UTD) are ray methods. They model each part of the surface as a small flat mirror. Engineers use them for the RCS of full aircraft and ships at X-band, and for reflector antennas. For a reflector, solve the feed horn with FEM or MoM. Then, use PO to put its pattern on the dish.

Quasi-static

The object is much smaller than a wavelength

A structure that is much smaller than a wavelength operates like a circuit. A common limit is λ/20, and λ/100 is safe. Quasi-static extractors calculate R, L, C and G more quickly than a full-wave solve. They do not model radiation or distributed (transmission-line) effects.

Hybrids

Most suites include many solvers

CST, Feko and HFSS each include time-domain, frequency-domain, integral-equation and asymptotic solvers. Hybrids such as FE-BI, or MoM with PO, use a different method for each part of a problem. Usually, you must select a solver in the suite that you have.

Worked example: a patch antenna in FEM

These are the steps of one real simulation, from the model to a checked result. The numbers are typical for a 5 GHz patch on a laptop. Your numbers will be different.

  1. Model

    Draw the patch, the feed line, the substrate (εr 3.5) and the ground plane. Give each part its material.

  2. Air box

    Put an air box around the antenna. Keep its walls λ/4 (15 mm) from the antenna. Apply a radiation boundary or a PML to the walls.

  3. Port

    Put a wave port on the end of the feed line. The port solve gives the line mode and its impedance.

  4. Adaptive mesh

    Set the solution frequency to 5 GHz and the target ΔS to 0.02. The mesh goes from approximately 5,000 to 25,000 tetrahedra in 6 passes, approximately 30 percent more for each pass. Memory is approximately 1 GB. See this loop in the FEM convergence demo.

  5. Frequency sweep

    Do an interpolating sweep from 3 to 7 GHz. It takes approximately 1 to 3 minutes. Then calculate the far-field pattern on a sphere.

  6. Check

    Solve again with 2.5D MoM. The two resonance frequencies usually agree within 1 to 3 percent. The pattern and the back lobe will be different, because the 2.5D model has an infinite ground plane. Make sure that |S11| is less than 1 at all frequencies.

Tools

The list shows commercial suites, and open-source and free alternatives. A tool is in the list for each method that it supports. The number on each card is the count of papers since 2020 that mention the tool. It shows research use, not industry use.

Free paths that work

PCB and RF parts, no licence

openEMS (FDTD) with Python scripts. Use scikit-rf to read, plot and check the S-parameters. The setup takes more time than with a commercial GUI.

On-chip, open PDK

gds2palace and gds2openEMS turn IHP SG13G2 GDSII layouts into Palace (FEM) or openEMS (FDTD) models. Both are open source.

Planar circuits

Sonnet Lite is free: up to 6 ports, 64 MB of memory and 2 metal levels. It is a good tool to learn planar EM.

Student editions

Ansys Electronics Desktop Student includes HFSS (limit: 64,000 elements, 4 cores). CST Studio Suite Learning Edition is free for non-commercial use, with a small mesh limit.

Pay for each run

Tidy3D runs GPU FDTD on the vendor cloud. You pay for each run. Your model data goes to the vendor. Some companies do not permit this.

Typical tool sets for a small team

MMIC and RFIC

ADS with Momentum and RFPro, or Microwave Office with AXIEM and Analyst, or Virtuoso with EMX. Add one 3D FEM tool for packages and bondwires.

Antennas and RF boards

One 3D suite: HFSS, CST Studio Suite or Simcenter Feko. Each suite has more than one method, so you can check one result with a second method.

PCB signal integrity

SIwave, Sigrity or HyperLynx for the full board. Use a 3D FEM tool for connectors and via transitions.

Open source

KLayout or gdsfactory for the layout, Gmsh for the mesh, Palace (FEM) and openEMS (FDTD) for the solve, and scikit-rf for the results.

Photonics

Lumerical or Tidy3D, with MEEP as the open-source check.

Most teams buy one 3D suite and one layout EM tool. Use the second method to check the first. These lists are examples. They are not recommendations.
